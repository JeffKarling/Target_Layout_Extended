# Security policy

## Reporting a vulnerability

The Target Layout Extended project takes the security of its code and build infrastructure seriously.

If you believe you have found a security vulnerability, please do not file a public issue. Disclose it responsibly through one of the following channels:

- Use GitHub private vulnerability reporting on the repository Security tab.
- Email the maintainer directly at `jeffkarling@proton.me`.

Provide detailed information about the vulnerability:
- A description of the issue and potential impact
- Affected component or target
- Step by step reproduction instructions or proof of concept
- Any potential mitigations or suggested fixes

## Response timeline

- Acknowledgment of report receipt within 48 hours
- Initial assessment and validation within 5 business days
- Coordinated disclosure timeline agreed upon with the reporter prior to any public advisory or release
